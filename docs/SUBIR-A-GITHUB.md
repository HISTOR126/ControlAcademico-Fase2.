# Crear el repositorio en HISTOR126 desde Chrome

El repositorio remoto no ha sido creado por esta entrega.

1. Extraiga el ZIP entregado. Abra la carpeta ControlAcademico-Fase2-Base.
2. En Chrome, abra GitHub y confirme que la sesión corresponde a HISTOR126.
3. Pulse + > New repository. Nombre sugerido: ControlAcademico-Fase2.
4. Elija la visibilidad que corresponda al trabajo y pulse Create repository.
5. En el repositorio nuevo, pulse uploading an existing file (o Add file > Upload files).
6. Arrastre el CONTENIDO de ControlAcademico-Fase2-Base, no el ZIP completo.
   README.md, src, docs, tests y wireframes deben quedar en la raíz del repositorio.
7. Incluya también .gitignore, .github y Directory.Build.props: algunos exploradores
   ocultan nombres que empiezan por punto. No suba bin ni obj.
8. Mensaje sugerido: "Importar base de Fase 1 y corregir reglas académicas".
9. Pulse Commit changes y compruebe que README.md aparece en la portada.
10. En Actions, revise que el flujo de compilación y pruebas termina correctamente.

El ZIP original en referencia conserva la entrega recibida pero no el historial de commits.
No borre ni modifique el repositorio de Marcelo. Conserve los créditos originales.
El README ya identifica la procedencia y distingue las mejoras.
